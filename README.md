# gfx-mini-suite-2

图形与多媒体领域第二批小项目集合，每个子目录独立可构建，各自带 `make test`。

| 子项目 | 语言 | 内容 |
|---|---|---|
| projects/mini-sat-poly | C11 | 2D 多边形 SAT 相交与点内判定 |
| projects/mini-gradient-map | C11 | Sobel 梯度幅值与边缘计数 |
| projects/mini-chroma-planar | C11 | RGB 与 YUV420 平面互转 |
| projects/mini-gain-stage | Python 3 | 静态增益与峰值均方根 |
| projects/mini-sprite-xform | C++17 | 精灵顶点变换与包围盒 |
| projects/mini-yuv-rotate | C11 | YUV420 平面旋转/镜像（90/180/270 + 镜像），色度采样点随几何变换，两种操作顺序逐字节一致 |

进入任一子目录执行 `make test` 即可。

## mini-yuv-rotate 说明

平面 YUV420（I420：Y/U/V 三平面，U/V 半宽半高）的旋转与镜像，
支持恒等、顺时针 90/180/270 度、水平/垂直镜像，任意宽高与行跨度
（含奇数）。Y 平面逐像素搬移，U/V 平面按色度格整体搬移。

关键约束：`rotate(rgb_to_yuv(A))` 与 `rgb_to_yuv(rotate(A))` 对三个
平面逐字节相等。标准相邻 2×2 块 + 边缘重复的 420 约定在奇数尺寸下
无法满足（镜像/旋转后边缘格的平均窗口像素数改变），因此本项目采用
对旋转/镜像二面体群等变的色度约定：

- 偶数长度轴：格 `i` 覆盖相邻像素 `{2i, 2i+1}`（标准做法）；
- 奇数长度轴：中心像素自成一格，其余以中心为不动点反射配对
  （格 0 = `{0, n-1}`，格 1 = `{1, n-2}`，……）；
- 二维色度格为两轴划分的笛卡尔积，色度值为格内像素色度的平均。

该划分在 90/180/270 度旋转与镜像下映射到自身，故恒等性对任意奇偶
尺寸成立。测试含三组尺寸的色差/字节一致性/计时，以及 1..13 全部
宽高组合 × 6 方向的穷举字节核对。
