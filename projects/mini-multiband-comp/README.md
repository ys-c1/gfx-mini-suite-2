# mini-multiband-comp

两频段（低频 / 高频）前馈压缩器，处理交错排列的浮点音频，纯标准库实现。

## 三段流水线

1. **分带** `split_mono`：互补一阶分频。低频带为 EMA 低通
   `y += a*(x-y)`，高频带取互补余项 `hp = x - lp`，因此
   `lp + hp == x`（重建误差仅为浮点舍入，测试中 < 1e-12）。
2. **逐带压缩** `compress_band`：峰值包络跟随（attack/release）驱动
   静态阈值/比率曲线，阈值以上
   `y = T * (env/T)^(1/R)`，阈值以下增益恒为 1。
3. **合并与峰值检查**：分通道求和后统计总峰值、各通道峰值，并在
   `peak > 1.0` 时置 `overload=True`。

`multiband_compress(..., enabled=False)` 直接拷贝输入，逐浮点不变，
即关闭分带时输出与现有行为完全相同。

## 报错条件（均为 ValueError）

- 频带边界倒置、重复，或落在 `(0, 奈奎斯特)` 开区间之外；
- 压缩比率为零或为负（`1/R` 在 R=0 无定义）；
- 样本数不能被通道数整除，或通道数 < 1。

## 命令

```
make test    # 11 项单元测试，含手算对照与过载用例
make bench   # 2 声道 / 6 声道基准，报告写到 ../../artifacts/
```

基准输出包含：输入/输出峰值、逐样本最大差、低/高频带最大压缩量(dB)、
每次运行耗时，以及用闭式传递函数和独立标量递推完成的手算对照。
