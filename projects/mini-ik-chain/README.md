# mini-ik-chain

三层平面骨骼（3 关节串联链）逆向运动学，纯 C11，无外部依赖。

## 模型

角度为相对父骨骼的局部转角（弧度），从基座正向累积：

```
关节 i 的世界朝向 = theta[0] + ... + theta[i]
末端 = base + Σ len[i] · (cos(朝向_i), sin(朝向_i))
```

## 求解器（CCD，Cyclic Coordinate Descent）

每轮从末端关节向基座依次旋转，把“关节→末端”方向对准“关节→目标”方向：

- **关节限位**：`[lo, hi]` 为硬约束，每次更新后夹紧；
- **帧间角度变化上限**：`max_step` 是逐迭代的信赖域——单次迭代单关节转角
  不超过该值，帧内可多步推进。解不会跳变，也不会因预算耗尽而无法收敛；
- **不可达目标**：记录整个迭代过程中残差最小的可达构型并返回，
  `reached=0` 且给出残差，绝不只报失败；
- **迭代上界**：`max_iter` 为硬上界，到界即停并返回当前最优；
- **可复现**：无随机数、固定更新顺序，相同输入逐位一致。
