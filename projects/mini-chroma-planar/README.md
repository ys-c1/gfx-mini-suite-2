# mini-chroma-planar

RGB 与平面 YUV 互转，支持 4:2:0 与 4:2:2 两种色度采样及可切换的转换矩阵。

## 模块

| 文件 | 内容 |
|---|---|
| `src/chroma.h/.c` | 原 RGB↔YUV420 路径（BT.601 full-range），**未改动** |
| `src/yuvconv.h/.c` | 新增：422↔420 互转、矩阵可切换（BT.601/BT.709）的 RGB↔YUV420 |
| `tests/test_chroma.c` | 原测试，仍全部通过 |
| `tests/test_yuvconv.c` | 新接口单元测试（失败码、亮度不动、奇数尺寸、往返、矩阵） |
| `bench/bench_yuvconv.c` | 四组尺寸的色差 RMS / 往返一致性 / 耗时报告 |

`make test` 跑两组测试，`make bench` 出报告。

## 色度尺寸与边界（奇数宽高）

亮度面 w×h 时：

| 格式 | 色度列数 | 色度行数 |
|---|---|---|
| 4:2:0 | ⌈w/2⌉ = (w+1)/2 | ⌈h/2⌉ = (h+1)/2 |
| 4:2:2 | ⌈w/2⌉ = (w+1)/2 | h |

- 奇数宽：最后一列色度只覆盖最后一列亮度（右边界无配对列）。
- 奇数高（仅 4:2:0）：最后一行色度只覆盖最后一行亮度。
- 垂直重采样滤波在首/末行外复制边缘行（clamp），不越界读。
- 用 `yc_chroma_dims(fmt, w, h, &cw, &ch)` 查询，与转换内部口径一致。

## 422↔420 互转（`yuv_convert`）

- **亮度逐像素不动**：Y 面原样拷贝（允许 `y_dst == y_src` 原地），所有处理只发生在色度面。
- **插值方向与采样方向一致**：两种格式水平采样相同（均 ⌈w/2⌉ 列），差异只在垂直方向，因此只做垂直滤波，水平逐列独立、绝不横向混合。
  - 422→420：垂直 2:1 抽取，`[1 3 3 1]/8` 滤波，输出第 j 行对齐亮度行 2j+0.5（MPEG 风格居中相位）。
  - 420→422：相位对齐垂直线性插值——偶数行 `0.25·c[j-1]+0.75·c[j]`，奇数行 `0.75·c[j]+0.25·c[j+1]`。
- 往返（420→422→420）的复合核为 `[3 10 3]/16`，是保直流的轻度平滑：渐变区域几乎无损，逐像素噪声级高频色度会有有界损失（基准见下）。

## 失败码

| 码 | 含义 |
|---|---|
| `YC_OK` (0) | 成功 |
| `YC_ERR_ARG` (-1) | 空指针参数 |
| `YC_ERR_FORMAT` (-2) | 未知像素格式或未知矩阵 |
| `YC_ERR_SIZE` (-3) | 尺寸非法（w/h≤0）或 stride 小于平面宽度（尺寸不匹配） |
| `YC_ERR_BUFFER` (-4) | 输出缓冲容量不足（按 `(行数-1)·stride + 列数` 核算，不足则整体拒绝、不写输出） |

## 矩阵切换对色差的影响

`rgb_to_yuv420_m` / `yuv420_to_rgb_m` 接受 `YC_MATRIX_BT601` / `YC_MATRIX_BT709`（均 full-range）。`matrix == YC_MATRIX_BT601` 时与原 `chroma.h` 路径**逐字节一致**（有测试保证）。

- 矩阵只影响 RGB↔YUV 的系数；422↔420 重采样在 YUV 域进行，与矩阵无关。
- 同一 RGB 源用两种矩阵转换，色度系统性偏移：基准图上 U 的 RMS 差约 5.6、V 约 4.5（8 级量化单位），亮度 RMS 差约 1~2。**采集链路与显示链路矩阵必须一致**，混用会产生恒定色调偏移（偏绿/偏紫），其幅度远大于 422↔420 重采样本身的往返损耗。
- 切换矩阵不改变色度面尺寸、stride 核算与失败码语义。

## 基准（`make bench`，本机 -O2）

测试图：水平/垂直渐变叠加 8px 棋盘（刻意含高频色度）。四组尺寸含一组奇数宽高 641×479。

| 尺寸 | 420→422→420 RMS U/V (max) | 422→420→422 RMS U/V (max) | 逐值不变比例 U/V | 422→420 ms | 420→422 ms |
|---|---|---|---|---|---|
| 320×240 | 13.2 / 2.2 (19/4) | 8.7 / 1.5 (15/3) | 51.7% / 49.3% | 0.022 | 0.036 |
| 640×480 | 13.3 / 2.1 (19/4) | 8.8 / 1.5 (15/3) | 50.8% / 50.8% | 0.089 | 0.148 |
| 1280×720 | 13.4 / 2.1 (19/3) | 8.8 / 1.4 (15/3) | 50.6% / 50.6% | 0.277 | 0.458 |
| 641×479 | 13.3 / 2.1 (19/4) | 8.8 / 1.5 (15/3) | 50.8% / 50.8% | 0.086 | 0.154 |

U 通道 RMS 偏高源于棋盘图案在蓝色通道的极端高频色度——2:1 垂直抽取必然衰减该频率；自然图像的实测损耗远低于此。逐值不变比例约 50% 与 `[3 10 3]/16` 平滑核的 ±1 量化抖动一致。
